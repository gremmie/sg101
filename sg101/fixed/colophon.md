## Colophon

[SurfGuitar101.com][sg101] was created by Brian Neal. The server-side code is
written in the [Python][python] programming language using the awesome
[Django][django] Web framework. The page layout and styling are built on the
[Foundation][foundation] framework, and client-side coding was done in
[JavaScript][javascript], making heavy use of the [jQuery][jquery] and
[jQuery UI][jqueryui] libraries. Icons courtesy of [FamFamFam][famfamfam].

The following 3rd party libraries were leveraged in the construction of this
site: [Celery][celery], [Pillow][pillow], [Python-Markdown][markdown], and
[Bleach][bleach].

The site runs on an infrastructure powered by many open-source tools: the
[Apache HTTP Server][apache] in front of [Gunicorn][gunicorn], a
[PostgreSQL][postgresql] database, and [Redis][redis]. The server is running
[Ubuntu][ubuntu], an operating system based upon the [Debian][debian]
[GNU][gnu] / [Linux][linux] distribution.

Special thanks to the beta testers who put the current version of the site
through its paces before it went live: Chuck Backus, Brian Fady, Ran Mosessco,
Emilio Nava, and synchro.

Thanks also to those who helped with a previous iteration of the site. The
original design was created by Ken Dushane of the band
The Crashmatics. Various icons and graphics were contributed by
Ariel (DreadInBabylon), Ferenc Dobronyi, and Joseph Koch. Abraham Aguilar and
Brian Fady provided useful feedback and testing.
