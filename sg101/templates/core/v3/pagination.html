{% comment %} Previous and Next are buttons at every width, an icon and a word. On a phone the page numbers and the words are hidden, and First, Last and the page the reader is on join the icons. A greyed button at either end leads nowhere, so it is hidden from screen readers. The icons are Foundation's media-player glyphs, whose names run the other way from the buttons': fi-previous is skip-to-start, so First, and fi-next is skip-to-end, so Last. {% endcomment %}
