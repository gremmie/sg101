Help with markup

SurfGuitar101.com uses a variation of the markup language called Markdown. This is the same markup used by Reddit. Markdown is a light-weight and easy-to-use syntax for styling text on the web. Here is a quick overview of how to use Markdown on SG101.

Emphasis
*This text will be italic* _This will also be italic_ **This text will be bold** __This will also be bold__ _You can **combine** these_
Lists
* Bulleted list item 1 * Bulleted list item 2 1. Numbered list item 1 2. Numbered list item 2 * You can have sub-lists * if you indent 4 spaces
Links
https://surfguitar101.com - automatic! [SurfGuitar101](https://surfguitar101.com)
Images
![Image](https://example.com/a.jpg)

Note: for security reasons, please use the Hot-Link () or Upload () buttons to add images to your posts.

Quoting
Dick Dale said: > The kids called me King of the Surf Guitar. This is not part of the quote because of the blank line.
Be sure to put a blank line above and below your quote.
