Colophon

SurfGuitar101.com was created by Brian Neal. The server-side code is written in the Python programming language using the awesome Django Web framework. The page layout and styling are built on the Foundation framework, and client-side coding was done in JavaScript, making heavy use of the jQuery and jQuery UI libraries. Icons courtesy of FamFamFam.

The following 3rd party libraries were leveraged in the construction of this site: Celery, Pillow, Python-Markdown, and Bleach.

The site runs on an infrastructure powered by many open-source tools: the Apache HTTP Server in front of Gunicorn, a PostgreSQL database, and Redis. The server is running Ubuntu, an operating system based upon the Debian GNU / Linux distribution.

Special thanks to the beta testers who put the current version of the site through its paces before it went live: Chuck Backus, Brian Fady, Ran Mosessco, Emilio Nava, and synchro.

Thanks also to those who helped with a previous iteration of the site. The original design was created by Ken Dushane of the band The Crashmatics. Various icons and graphics were contributed by Ariel (DreadInBabylon), Ferenc Dobronyi, and Joseph Koch. Abraham Aguilar and Brian Fady provided useful feedback and testing.
